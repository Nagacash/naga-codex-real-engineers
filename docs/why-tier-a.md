# Why Tier A

Matt Pocock–style engineering skills fix **process failure modes** (misalignment,
missing tests, mushy review). Naga Codex Cyber Security fixes **security consulting**
delivery. They complement; they are not the same product.

Tier A is deliberately small (6 skills):

| Skill | Role |
|-------|------|
| ask-naga | Router |
| naga-align | Kill misalignment |
| naga-context | Shared language |
| naga-tdd | Red-green-refactor |
| naga-review | Standards ∥ Spec |
| naga-ship | Orchestrator |

No straight copy of third-party skill bodies. Patterns only; original Naga text.
